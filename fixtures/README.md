# Fixture media

Fixtures support development and deterministic tests. They are not representative evaluation data and must not be presented as live provider output or inspection results.

## Catalog labeling

The app's catalog uses a demo label. Its modeled areas and prompts support the prototype workflow; they are not a claim that every label is an authoritative or provider-approved Form 1083 mapping. See the [Form 1083 integration guide](../docs/integration/FORM_1083_MAPPING.md).

## Included media

`fixtures/media/dev-ceiling-detector-01.jpg` is a self-shot development image with metadata removed. It is not evaluation footage and must not be used to claim video or inspection quality. Synthetic video and image inputs used by automated tests are documented in [the browser test fixture notes](../tests/fixtures/README.md).

## Evaluation media

No evaluation media is included in this repository. Follow the [evaluation protocol](../docs/evaluation/protocol.md) and record provenance, rights, sample size, and observed limitations before reporting evaluation results. Never use tenant or personally identifying media.
